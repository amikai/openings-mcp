# freehire

`openapi.yaml` is https://freehire.me/openapi.yaml, used unmodified.

`testdata/*.hurl` pins the behaviour a caller has to know before trusting
a filtered result against the live API — `jobs_ignored_params_req.hurl`
and `jobs_deep_page_req.hurl` in particular cover behaviour
`openapi.yaml` states in prose only.
